# Roadmap

- [x] Core engine, identity across channels, safety rail
- [x] Adapters: voice, USSD, SMS, WhatsApp
- [x] Context pack specification 0.1 and loader
- [x] MCP server with `query_context`
- [x] M-Pesa STK Push request builder
- [ ] Persistent profile and context stores
- [ ] Webhook signature verification per provider
- [ ] Speech providers for Swahili and English, evaluated on a public benchmark
- [ ] Agent app for agro-dealers and extension officers
- [ ] First expert reviewed Kenya agriculture pack
- [ ] One partner live on the verified tier

- [ ] Rwanda and Uganda: Kinyarwanda, Luganda; MTN MoMo and Airtel Money connectors

- [ ] Francophone West Africa: Wolof, Pulaar; Orange Money connector
