Put ACE behind your channel or your assistant.

One JSON call returns a grounded answer with its sources, or the national emergency numbers when the message needs them. AI assistants connect over MCP. No key is needed for this demonstration.

Ask a question

curl https://ace.korext.com/v1/ask \
  -H "Content-Type: application/json" \
  -d '{"text": "how do I store maize", "country": "KE", "channel": "sms"}'

The reply carries text, kind (answer, emergency, scam, clarify or system), language, escalated, and citations, each with its source, link, licence, checked date and review status. With "channel": "sms" it also returns the SMS segments.

Country and language

Pass country as an ISO code, such as NG, SN or ZA. It decides the facts, the services and the emergency numbers. A request with no country is answered as from outside ACE's 34 countries: guidance that applies everywhere, and an emergency is told to call the local emergency number, never another country's lines.

This public server ignores a phone field, so no caller can act as a real subscriber, and it keeps no profile for an API call. Pass language to choose the reply language, or leave it out and ACE reads it from the message among the country's languages.

Decision services

curl https://ace.korext.com/v1/services/rain_this_week \
  -H "Content-Type: application/json" \
  -d '{"country": "GH", "place": "Ashanti", "language": "en"}'

Services: rain_this_week, official_warnings, nearest_facility, market_prices (add food), pregnancy_companion (add weeks) and pest_check (add text). Each result carries outcome (answer, needs_place, gap, stale or no_match), preview, its citations and the structured data behind the text. GET /v1/services lists every service and its coverage by country.

Scam Shield and emergency numbers

curl https://ace.korext.com/v1/scam \
  -H "Content-Type: application/json" \
  -d '{"text": "Your SIM is registered twice. Send your PIN to confirm", "country": "KE"}'

curl "https://ace.korext.com/v1/emergency?country=NG&queue=gbv"

Scam Shield never declares a message safe. Emergency queues: emergency, health_urgent, maternal, poisoning, gbv, violence, child_protection, self_harm and fire.

MCP for assistants

Add this address to any assistant that speaks MCP over Streamable HTTP:

https://ace.korext.com/mcp

Tools: ask_ace, search_context, check_message, emergency_contacts, list_packs, and one per service: rain_this_week, official_warnings, nearest_facility, market_prices, pregnancy_companion, pest_check and service_coverage. Every tool is read only, sends no messages, and takes the country when the assistant knows it. No tool assumes a country.

Limits and terms

  • Requests are limited per address, generously, because many mobile users share one carrier address. A client that goes over gets HTTP 429 and can retry after a minute.
  • This is a demonstration with no service level. For production, run your own copy.
  • Code under Apache 2.0. Knowledge packs under CC BY 4.0, language profiles under CC BY-SA 4.0, and each snapshot under its source's licence, named in every citation. Weather comes from Open-Meteo's free tier and is credited in every weather answer.

Run your own

Everything that runs this site is in the repository: pip install ace-engine from the release wheel, ace serve on your own machine, or the Google Cloud scripts in deploy/gcp, which stand up the same stack in any project.
