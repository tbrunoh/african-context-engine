Every fact is `sourced`: a maintainer compared it with the cited public source on the `checked_on` date. None is expert reviewed yet, and every Swahili rendering awaits review by a fluent speaker. Both are open invitations: see [docs/good-first-issues.md](../docs/good-first-issues.md).

To add a pack, copy [_template.yaml](_template.yaml), follow [docs/context-packs.md](../docs/context-packs.md), run `ace packs validate`, and open a pull request with the context pack template.
