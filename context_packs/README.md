# Context packs

Open tier packs live here under CC BY 4.0. Verified tier packs never ship in this repository.

- `examples/kenya-maize-demo.yaml`: a development pack that shows geographic, altitude and seasonal scoping. Every fact is a draft or a placeholder. It is not agronomic advice.

To add a pack, follow [docs/context-packs.md](../docs/context-packs.md) and open a pull request with the Context pack issue template.
